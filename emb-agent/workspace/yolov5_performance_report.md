## 6. 性能分析

### 6.1 推理速度
- 单张图片推理平均耗时 **112.54 ms**，约 **8.88 FPS**
- 对于嵌入式设备而言，性能表现中等
- 主要瓶颈在 CPU 推理，ncnn 已针对 ARM 优化

### 6.2 CPU 利用率
- 推理时 CPU 利用率较高（单次推理约 0.3s user time）
- 4核CPU在推理时并行计算，ncnn 利用了多核优势

### 6.3 内存占用
- 程序运行期间内存占用很低（~286 MB 已用）
- 推理完成后内存完全释放，无内存泄漏

### 6.4 温度表现
- 32°C 运行温度非常理想，散热系统工作良好

## 7. 优化建议

| 方向 | 建议 | 预期提升 |
|------|------|---------|
| **模型量化** | 使用 INT8 量化模型 (已有 i8s.bin/i8s.param) | 推理速度提升 2-3 倍 |
| **多线程** | 调整 ncnn 的线程数，充分利用 4 核 | 10-20% 提升 |
| **模型剪枝** | 使用更轻量的 YOLOv5-Lite 变体 | 20-30% 提升 |
| **NPU 加速** | 如飞腾派支持 NPU，可卸载推理任务 | 5-10 倍提升 |

## 8. 结论

YOLOv5-Lite (ncnn) 在飞腾派上运行稳定，单张 640x424 图片推理平均耗时 **112.54ms** (~8.88 FPS)。系统资源占用低，温度控制良好。通过 INT8 量化可进一步提升推理速度，适合在嵌入式场景中部署。
